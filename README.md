# Twitter Archive for Muse

Twitter / X のアーカイブから必要なデータを取り出し、Muse から参照するためのリポジトリです。

## 現在の状態

リポジトリの準備が完了しました。アーカイブのデータはまだ追加されていません。

## データの配置予定

- `data/`: 参照対象の投稿データ。必要に応じて複数のテキストファイルに分割します。
- `INDEX.md`: データファイルへのリンクと収録範囲。データ追加時に作成します。

## Muse からの参照

データ追加後、`INDEX.md` と対象データファイルの URL を Muse に渡します。実際に読み込めるかどうかは Muse 側での確認が必要です。ZIP のダウンロード URL だけでは、内容を読み取れない場合があります。

## 公開範囲

このリポジトリは初期準備時点で公開設定です。データ追加前に内容を確認し、DM、連絡先などの非公開情報を含めないようにします。
